Articles live here, one Markdown file per article, written in the site editor at `/admin` or
by hand. The file name is the article's address: `my-first-article.md` is published at
`/articles/my-first-article`. Front matter:

```yaml
---
title: The article's headline
date: 2026-11-12          # publication date
author: Your name
category: Congress        # Congress, Elections or Analysis
summary: One or two sentences for the cards and search results.
image: /uploads/picture.jpg   # optional
draft: false              # true keeps it off the site
---
```
